📋 Ficha de Especificación Formal - CU30

Módulo Contabilidad
CU30 - Consultar Libros Contables (Diario y Mayor) Descripción
Propósito Permitir al personal contable y administrativo consultar, auditar y exportar los registros oficiales de transacciones económicas en formato de Libro Diario (asientos cronológicos detallados por partida doble) y Libro Mayor (movimientos y saldos acumulados progresivos agrupados por cada cuenta contable del catálogo), filtrables por periodo contable, cuenta y rango de fechas.
Actores Contador del ERP, Auxiliar Contable, Auditor, Administrador del Sistema.
Iniciador Contador del ERP / Auxiliar Contable.
Precondiciones • El usuario debe haber iniciado sesión en el sistema y contar con permisos de consulta en el módulo contable.
• Debe existir al menos un periodo contable registrado en la empresa.
• El catálogo de cuentas contables debe estar cargado y contar con cuentas que admiten movimiento.
• Deben existir asientos contables registrados en el sistema.
Flujo Principal 1. El usuario selecciona la opción Consultar Libros Contables dentro del módulo de Contabilidad y Finanzas.
2. El sistema despliega la interfaz con dos vistas principales: Libro Diario y Libro Mayor, cargando por defecto el Libro Diario con los filtros del periodo en curso.
3. Consulta del Libro Diario:
    a. El usuario selecciona los criterios: periodo contable, rango de fechas (desde / hasta), tipo de asiento y estado.
    b. El usuario presiona el botón Consultar.
    c. El sistema valida los filtros y recupera los asientos en orden cronológico ascendente por fecha y correlativo.
    d. El sistema muestra para cada asiento su número, fecha, tipo, glosa, estado y las líneas de detalle con cuentas, Debe y Haber.
    e. El sistema totaliza las columnas Debe y Haber, confirmando la partida doble.
4. Consulta del Libro Mayor:
    a. El usuario cambia a la pestaña de Libro Mayor.
    b. El usuario selecciona una cuenta contable (o todas) y el intervalo de fechas.
    c. El usuario presiona Consultar Mayor.
    d. El sistema calcula el Saldo Inicial anterior a la fecha de inicio según la naturaleza de la cuenta (deudora o acreedora).
    e. El sistema lista cronológicamente los movimientos, débitos, créditos y el saldo acumulado en cada línea.
    f. El sistema presenta el resumen de la cuenta con Total Débitos, Total Créditos y Saldo Actual de cierre.
5. El usuario puede solicitar la exportación de los libros contables a documento PDF, CSV o vista imprimible.
6. El sistema genera el archivo con el membrete oficial, NIT, periodo consultado y firmas de responsabilidad.
Postcondiciones • La información de los libros contables queda visualizada en pantalla para su análisis y auditoría sin alterar los registros en la base de datos.
• Si el usuario solicitó exportar, se descarga el reporte contable formateado.
Excepciones • E1: Rango de fechas inválido: La fecha inicial es posterior a la final. El sistema notifica la inconsistencia y no ejecuta la consulta.
• E2: Sin movimientos en el periodo: No existen asientos que cumplan los filtros seleccionados. El sistema muestra mensaje informativo.
• E3: Cuenta sin movimiento: Se intenta consultar el mayor de una cuenta de agrupación (padre). El sistema advierte que el mayor solo aplica a cuentas analíticas de último nivel.

📈 Ficha de Especificación Formal - CU31

Reportes Financieros
CU31 - Consultar Información Financiera Descripción
Propósito Permitir a los directores, administradores y personal contable generar, analizar y exportar los Estados Financieros oficiales de la empresa: el Balance General (situación de Activos, Pasivos y Patrimonio con verificación de la ecuación patrimonial) y el Estado de Resultados (cálculo de Ingresos, Costos, Gastos y Utilidad/Pérdida Neta) para una gestión, periodo contable o fecha de corte seleccionada.
Actores Gerente General, Director Financiero, Contador del ERP, Auditor, Administrador.
Iniciador Contador del ERP / Gerente General.
Precondiciones • El usuario debe haber iniciado sesión con permisos para consultar información financiera.
• El plan de cuentas debe tener definidas correctamente las clasificaciones de Activo, Pasivo, Patrimonio, Ingresos y Egresos.
• Deben existir asientos contables mayorizados correspondientes al periodo a evaluar.
Flujo Principal 1. El usuario ingresa a la opción Consultar Información Financiera dentro de Contabilidad y Finanzas.
2. El sistema despliega la interfaz con dos reportes: Balance General y Estado de Resultados, cargando por defecto el Balance General y la gestión actual.
3. Generación del Balance General:
    a. El usuario selecciona la gestión contable, fecha o mes de corte y el nivel de profundidad de cuentas.
    b. El usuario presiona Generar Balance General.
    c. El sistema calcula los saldos acumulados hasta la fecha de corte para Activos, Pasivos y Patrimonio.
    d. El sistema calcula el Resultado del Ejercicio (Ingresos acumulados menos Costos y Gastos a la fecha) y lo incorpora en el Patrimonio.
    e. El sistema estructura y presenta el reporte jerárquico: Total Activo (Corriente y No Corriente), Total Pasivo y Total Patrimonio.
    f. El sistema valida la ecuación: Total Activo = Total Pasivo + Total Patrimonio y exhibe el indicador de balance cuadrado.
4. Generación del Estado de Resultados:
    a. El usuario selecciona la pestaña Estado de Resultados.
    b. El usuario define el intervalo de fechas a evaluar y el nivel de cuentas.
    c. El usuario presiona Generar Estado de Resultados.
    d. El sistema procesa los ingresos y egresos: Ingresos Operativos menos Costo de Ventas (Utilidad Bruta), deducción de Gastos Operativos (Resultado Operativo) y otros rubros para determinar la Utilidad Neta.
    e. El sistema muestra la Utilidad o Pérdida Neta del Ejercicio con el porcentaje vertical de cada rubro.
5. El usuario puede exportar los reportes a PDF o Excel.
6. El sistema emite el documento oficial con identificación corporativa y casillas de firma.
Postcondiciones • La situación patrimonial y económica de la empresa queda expuesta para análisis gerencial y fiscalización.
• Si se solicitó la exportación, se emite el informe financiero formal.
Excepciones • E1: Periodo sin registros contables: No existen transacciones en el periodo. El sistema advierte que no es posible generar el estado financiero.
• E2: Descuadre en ecuación patrimonial: Por desbalance en asientos o cuentas sin clasificación, la ecuación no iguala. El sistema alerta la diferencia en rojo para su revisión contable.
• E3: Parámetros temporales inconsistentes: Rango de fechas inválido.

HU30 Consultar Libros Contables Alta Por hacer
Como Contador del ERP (responsable de la contabilidad y fiscalización).
Quiero Consultar, filtrar y exportar los registros del Libro Diario y del Libro Mayor general de la empresa.
Para Auditar la cronología de las operaciones contables, verificar el cumplimiento de la partida doble y conocer el saldo histórico de cada cuenta contable.
Criterios de aceptación
◆ Selección de vista: El sistema debe permitir alternar fácilmente entre la vista del Libro Diario y la vista del Libro Mayor.
◆ Filtros del Libro Diario: Se debe poder filtrar por periodo contable, rango de fechas (desde / hasta), tipo de asiento (Diario, Ingreso, Egreso, Traspaso, Ajuste o Todos) y estado del asiento (Borrador, Mayorizado o Todos).
◆ Detalle del Libro Diario: Cada asiento del Libro Diario debe mostrar su fecha, número correlativo, tipo de comprobante, glosa general, estado y el desglose de cada una de sus cuentas con código, nombre y sus montos en el Debe o en el Haber.
◆ Verificación de partida doble: El sistema debe calcular y mostrar el total del Debe y el total del Haber del conjunto de asientos consultados, evidenciando que ambas sumas sean exactamente iguales.
◆ Filtros del Libro Mayor: Se debe poder consultar el mayor seleccionando una cuenta contable específica o todas las cuentas de movimiento, dentro de un periodo contable o rango de fechas definido.
◆ Saldo anterior en el Mayor: El sistema debe calcular y mostrar el saldo inicial acumulado antes de la fecha inicial seleccionada, sumando o restando débitos y créditos según la naturaleza de la cuenta (deudora o acreedora).
◆ Movimientos y saldo progresivo: Cada movimiento en el Libro Mayor debe exhibir su fecha, número de asiento origen, concepto o glosa, importe en el Debe, importe en el Haber y el saldo resultante actualizado fila por fila.
◆ Resumen de cuenta: Al final de cada cuenta en el Mayor, el sistema debe presentar el Total Débitos del periodo, Total Créditos del periodo y el Saldo Final.
◆ Cuentas analíticas: La consulta del Libro Mayor solo debe permitir seleccionar cuentas que admiten movimientos (cuentas de último nivel); las cuentas de agrupación no deben emitir mayor individual.
◆ Exportación: El sistema debe permitir descargar los reportes en formato PDF y hoja de cálculo para su archivo físico o presentación ante auditorías.
◆ Permisos de acceso: La consulta de libros contables debe estar reservada exclusivamente para usuarios que cuenten con autorización de consulta contable; usuarios no autorizados no podrán visualizar la información.
Conversación / reglas • Los asientos generados automáticamente por ventas, cobros, compras o notas de crédito se reflejan en el Libro Diario con su respectiva referencia al documento comercial.
• Por defecto, la consulta de libros contables presenta únicamente asientos en estado mayorizado para asegurar la veracidad de la información oficial.
• El orden del Libro Diario siempre es estrictamente cronológico ascendente (por fecha y número de asiento).
• Si se ingresa una fecha final anterior a la fecha inicial, el sistema impide la búsqueda y solicita corregir el rango.
• Toda consulta y exportación queda registrada en la bitácora de auditoría del sistema para control de accesos a información financiera sensible.

HU31 Consultar Información Financiera Alta Por hacer
Como Gerente General o Contador del ERP.
Quiero Generar y analizar el Balance General y el Estado de Resultados de la empresa para un periodo contable o fecha de corte seleccionada.
Para Conocer la situación patrimonial real de la empresa, evaluar las utilidades o pérdidas del negocio y sustentar decisiones estratégicas y tributarias.
Criterios de aceptación
◆ Elección de estado financiero: El sistema debe permitir seleccionar claramente entre generar el Balance General (Estado de Situación Patrimonial) o el Estado de Resultados (Pérdidas y Ganancias).
◆ Filtros temporales: Para el Balance General se debe poder seleccionar la gestión y el mes o fecha exacta de corte. Para el Estado de Resultados se debe poder seleccionar el periodo de tiempo o intervalo de fechas a evaluar.
◆ Niveles de agrupación: El usuario debe poder definir el nivel de profundidad de visualización en el árbol de cuentas (solo grupos principales, subgrupos o cuentas detalladas de movimiento).
◆ Estructura del Balance General: El reporte debe clasificar claramente los saldos en Activo (Corriente y No Corriente), Pasivo (Corriente y No Corriente) y Patrimonio (Capital, Reservas y Resultados).
◆ Incorporación de la utilidad del ejercicio: El Balance General debe calcular automáticamente la Utilidad o Pérdida Neta del periodo e incorporarla dentro del rubro de Patrimonio para reflejar el patrimonio neto actualizado.
◆ Validación de la ecuación patrimonial: El sistema debe verificar en tiempo real que Total Activo sea igual a Total Pasivo más Total Patrimonio. Si el balance cuadra exactamente, debe mostrar un indicador visible de confirmación; si existe diferencia, debe advertir el monto descuadrado.
◆ Estructura del Estado de Resultados: El reporte debe estructurarse de forma escalonada mostrando: Ingresos Operativos menos Costo de Ventas igual a Utilidad Bruta; deducción de Gastos Operativos igual a Resultado de Operación; y adición/deducción de otros ingresos y gastos para obtener la Utilidad o Pérdida Neta final.
◆ Análisis porcentual: El Estado de Resultados debe mostrar el porcentaje que representa cada costo y gasto respecto al total de ingresos operativos.
◆ Exportación formal: Se debe permitir la exportación de ambos estados financieros a formato PDF y hoja de cálculo con la razón social, NIT, periodo, fecha de emisión y espacios para las firmas oficiales de responsabilidad.
◆ Acceso restringido: Solo los usuarios con autorización específica para consultar finanzas corporativas tienen acceso a esta pantalla; cualquier otro rol tiene el acceso bloqueado.
Conversación / reglas • Solo se toman en cuenta asientos mayorizados para la emisión de los estados financieros; los borradores quedan excluidos para no distorsionar las cifras oficiales.
• Las cuentas sin movimientos ni saldos dentro del periodo seleccionado se pueden ocultar de la vista para mantener el reporte limpio y conciso.
• Si la empresa no cuenta con transacciones contables en el año consultado, el sistema muestra los rubros principales en saldo cero con un mensaje informativo.
• El formato de presentación debe cumplir con la estructura contable estándar aplicable a empresas comerciales y de servicios.
